# 知序 · 个人计算机学习知识库

无需安装依赖。需要 Python 3：

```powershell
python serve.py
```

然后在浏览器打开 <http://127.0.0.1:4174>。请通过本地 HTTP 地址访问，不要直接双击 `index.html`：浏览器需要安全上下文才能可靠使用 IndexedDB。

笔记、代码、图片、附件、文件夹和打卡记录保存在浏览器 IndexedDB；主题等偏好使用 LocalStorage。所有资料仅留在当前浏览器配置文件中，清除网站数据前请先从“设置与备份”导出 JSON 或 ZIP。恢复备份会替换当前资料。切换浏览器或设备不会自动同步。

支持笔记自动保存和 Markdown/富文本切换、预览分屏、文字颜色与高亮、图片/附件、打卡与补签、代码文件编辑和移动、分类/标签/日期筛选、全局搜索及完整 JSON/ZIP 导入导出。代码编辑器使用浏览器原生文本编辑器和轻量语法着色，不依赖在线 Monaco/CDN。
